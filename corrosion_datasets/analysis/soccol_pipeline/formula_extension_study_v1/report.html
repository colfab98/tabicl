Only the 2,950 accepted development rows were supplied to this study. All 805 final queries and 272 withheld development rows were excluded. These are development formula scores, not final-model results. Training formulas and sampling assets were not changed.

28 predeclared candidates: nine current rules, three tungsten updates, fourteen extensions, and two new equations. The current nine baseline scores were reproduced. The strongest existing development rule is the fixed anchor for extensions; it was previously selected on these development rows, so the study is exploratory.

The EPIT nested procedure selects regularization and formula inside each outer development fold. Filling values, scaling, category support, and base-rule coefficients use fitting rows only. The nested_new_and_existing row evaluates candidate selection; nested_existing_only applies the same selector to the original nine rules. Individual candidate scores can be optimistic when used to pick a winner.

The source_publication_blocked_folds diagnostic uses the same accepted development rows grouped by publication. It never replaces the frozen final-test partition. Uncertainty intervals resample held-out publication groups conditional on fitted models; they do not include research or fitting instability.

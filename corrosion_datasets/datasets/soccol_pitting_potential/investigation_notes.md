# Investigation Notes

Benchmark v1 implements the decisions needed for the current informed-versus-generic-versus-traditional model comparison. The raw workbooks remain unchanged.

## Implemented

1. All 24 false `2000Russell.Ti` PRE values are discarded in the processed data, then encoded as `Ti=0` and `Ti_missing=1`.
2. Composition blanks are zero-filled with one missingness indicator per element. This is an explicit benchmark encoding, not recovered chemistry.
3. `Fe` is computed as the approximate remainder only for rows where the material classification and reported major composition support it. Otherwise it is `Fe=0, Fe_missing=1`.
4. Mixed, Ni-based, Alloy 800, high-alloy, and uncertain rows receive row-level material-family and include/review/exclude audit flags. No family is silently removed.
5. The primary regression task uses the previous EPIT split design: compositions linked within an L1 distance of 1.0 wt.% stay together, with 3,222 development rows, 805 final-test rows, and five grouped development folds. Source is balanced and audited but does not define groups.
6. The primary regression table contains numeric `E_pit` rows with `event=1`; a separate censor-aware table retains defined `event` values.
7. Environmental blanks remain missing. Numeric imputation and categorical encoding must be fitted on training data only.

Preprocessing is generated by `prepare_benchmark.py`; the frozen split is generated by `prepare_composition_split.py`. Exact transformations, checksums, feature roles, and split assignments are under `processed/`.
